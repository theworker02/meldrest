# meldrest

Meld identifiers and rest tokens for idempotent workflows.

**Site:** https://theworker02.github.io/meldrest/

## Install / run

```bash
git clone https://github.com/theworker02/meldrest.git
cd meldrest
node src/cli.js
node --test
```
